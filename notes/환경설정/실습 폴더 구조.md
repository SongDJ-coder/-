# 실습 폴더 구조

실습 코드는 `C:\Deeplerning`에 있고, 공부 노트는 이 Obsidian 폴더에 있다.

```
C:\Deeplerning
├── .venv\                  ← 가상환경 (GitHub에 안 올림)
├── .vscode\settings.json   ← VS Code 설정
├── ch01_python\            ← 1장 파이썬·NumPy·matplotlib
├── ch02_perceptron\        ← 2장 퍼셉트론
├── ch03_neural_network\    ← 3장 신경망
├── ch04_learning\          ← 4장 신경망 학습
├── ch05_backprop\          ← 5장 오차역전파법
├── ch06_techniques\        ← 6장 학습 관련 기술
├── ch07_cnn\               ← 7장 CNN
├── ch08_deep\              ← 8장 딥러닝
├── common\                 ← 여러 장에서 같이 쓰는 함수·계층
├── dataset\                ← MNIST 데이터와 불러오는 코드
├── notes\                  ← Obsidian 노트 복사본 (sync_notes.ps1로 채움, 직접 수정 X)
├── .gitignore              ← GitHub에 안 올릴 파일 목록
├── sync_notes.ps1          ← Obsidian → notes\ 복사 스크립트
├── requirements.txt        ← 설치할 패키지 목록
└── README.md               ← 사용법 요약
```

## 만드는 명령 (PowerShell)
```powershell
cd C:\Deeplerning
$dirs = "ch01_python","ch02_perceptron","ch03_neural_network","ch04_learning",
        "ch05_backprop","ch06_techniques","ch07_cnn","ch08_deep","common","dataset","notes"
foreach ($d in $dirs) { New-Item -ItemType Directory -Force $d }
```

## 실행할 때 주의할 점
- 코드는 **`C:\Deeplerning`에서** 실행한다.
  ```powershell
  python ch03_neural_network\파일.py
  ```
- 이렇게 해야 각 장의 코드에서 아래처럼 불러올 수 있다.
  ```python
  from common.functions import ...
  from dataset.mnist import ...
  ```
- VS Code에서는 [[VS Code 설정]]의 `PYTHONPATH` 설정이 이 문제를 대신 해결해 준다.
