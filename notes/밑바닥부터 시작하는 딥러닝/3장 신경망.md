## 1. 퍼셉트론에서 신경망으로 (3.1)
- 입력층 → 은닉층 → 출력층. **가중치를 갖는 층(줄과 줄 사이)**만 센다.
  - 3줄(은닉층 1개) → 2층 신경망
  - 4줄(은닉층 2개, 3.4의 신경망) → **3층 신경망**
- 편향 $b = -\theta$로 쓰면: $a = b + w_1x_1 + w_2x_2$, $y = h(a)$
- $h()$가 **활성화 함수**: 가중합 $a$를 출력 $y$로 바꾸는 함수.

## 2. 활성화 함수 (3.2)

### 계단 함수
```python
def step_function(x):
    return np.array(x > 0, dtype=int)   # 또는 (x > 0).astype(int)
```
- `x > 0` → `True/False` 배열. `dtype=int`로 **1/0으로 바꾼다.**
- `np.array(...)`로 감싸면 숫자 하나를 넣어도 NumPy 배열이 나온다.
- ⚠️ 책의 `np.int`는 **NumPy 2에서 없어졌다** → 그냥 `int`.

### 시그모이드, ReLU
```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def relu(x):
    return np.maximum(0, x)   # np.max 아님!
```
- 배열을 넣으면 for문 없이 **원소마다** 계산된다 (브로드캐스트).

### 그래프 그리기 (pyplot)
```python
x = np.arange(-5.0, 5.0, 0.1)
plt.plot(x, sigmoid(x), label='sigmoid')
plt.plot(x, step_function(x), linestyle='--', label='step')
plt.ylim(-0.1, 1.1)
plt.legend()
plt.show()
```
| 코드 | 하는 일 |
|:-|:-|
| `plt.plot(x, y)` | `x[i]`, `y[i]`를 짝지어 점을 찍고 **선으로 연결**. 여러 번 부르면 겹쳐 그림 |
| `linestyle='--'` | 점선 |
| `label=` + `plt.legend()` | 범례. `legend()`를 불러야 보임 |
| `plt.ylim(아래, 위)` | y축 범위 |
| `plt.show()` | 맨 마지막에 보여 주기 |

- 계단 함수 그래프의 세로선은 0인 점과 1인 점을 `plot`이 **선으로 이어서** 생긴 것.
- 시그모이드 vs 계단: 둘 다 0~1, 둘 다 비선형. 시그모이드는 **매끄럽고** 계단은 0 아니면 1.

### 왜 비선형이어야 하나 ⭐
- 선형 $h(x) = cx$로 3층을 쌓으면 $h(h(h(x))) = c^3x$ → **1층과 완전히 똑같다.**
- 행렬로 봐도 $(XW_1)W_2 = X(W_1W_2)$ → 행렬 하나로 합쳐진다.
- 진동하지 않는다: 입력은 층을 **한 번씩만** 통과한다. 계수가 음수여도 기울기가 반대인 직선일 뿐.
- **왜 중요한가:** 1층이 못 하는 건 100층을 쌓아도 못 한다. 예) XOR을 선형으로 최대한 맞춰도 `[0.5, 0.5, 0.5, 0.5]`.
- 비선형(계단, 시그모이드, ReLU)이 있어야 층마다 "꺾임"이 더해져서 복잡한 문제를 푼다. ReLU 그래프의 0에서 꺾이는 부분이 그 비선형.

## 3. 다차원 배열의 계산 (3.3)

### ndim과 shape
| 코드 | 괄호 겹 = `ndim` | `shape` |
|:-|:-:|:-:|
| `np.array([1, 2])` | 1 | `(2,)` |
| `np.array([[1, 2]])` | 2 | `(1, 2)` |
| `np.array([[1], [2]])` | 2 | `(2, 1)` |
| `np.array([[1, 2], [3, 4], [5, 6]])` | 2 | `(3, 2)` |

- `(2,)`의 쉼표: 원소 하나짜리 **튜플**이라서. `(2)`는 그냥 숫자 2.
- `ndim` = 대괄호 겹 수 = `len(shape)`.
- `shape`는 **속성**이라 괄호 없이 `x.shape`. `x.shape()`는 에러.

### 행렬 곱
- `(행, 열) · (행, 열)` → **안쪽 숫자가 같아야** 하고, 결과는 **바깥 숫자**.
- `(2,3)·(3,2) → (2,2)`, `(2,)·(2,3) → (3,)`, `(2,3)·(2,2)` → 에러.

## 4. 3층 신경망 구현하기 (3.4)
```
입력(2) → 은닉1(3) → 은닉2(2) → 출력(2)
       W1(2,3)    W2(3,2)    W3(2,2)
```
$$A^{(1)} = XW^{(1)} + B^{(1)},\quad Z^{(1)} = h(A^{(1)})$$
- 앞 층의 출력 `Z1`이 다음 층의 입력. 은닉층은 시그모이드, 출력층은 **항등 함수**(받은 값 그대로).
- 항등 함수를 굳이 만드는 이유: 층마다 "가중합 → 활성화 함수" 흐름을 똑같이 맞추려고.
- `init_network()`로 가중치를 딕셔너리에 담고, `forward(network, x)`로 한 번에 계산.

### 가중치만 정하면 뭘 할 수 있나?
- 3장에서는 가중치를 **구하지 않는다.** 주어진 가중치로 출력을 **계산**(추론)한다.
- 4장 예제의 `0.1, 0.3, ...`은 아무 의미 없는 숫자 → 출력도 의미 없음. 흐름 연습용.
- **같은 코드**에 학습된 가중치를 넣으면 손글씨 숫자를 맞힌다 (3.6, 정확도 93.52%).

| 장 | 가중치는 어디서? |
|:-:|:-|
| 2장 | 사람이 직접 고름 |
| 3장 | 학습된 것을 받아서 사용 (추론) |
| 4장 | 데이터로 컴퓨터가 찾음 (학습) |

## 5. 출력층 설계하기 (3.5)
```python
def softmax(a):
    c = np.max(a)
    exp_a = np.exp(a - c)     # 오버플로 대책
    return exp_a / np.sum(exp_a)
```
- 그냥 `np.exp(1010)` → `inf`, `inf/inf` → `nan`. **최댓값을 빼도 결과는 같다.**
- 출력의 합은 1 → **확률**로 해석.
- `exp`는 순서를 안 바꿔서 `argmax`는 소프트맥스 전후가 같다 → 추론 때는 생략하기도.
- 분류 → 소프트맥스, 회귀 → 항등 함수. 출력층 뉴런 수 = 클래스 수 (숫자 0~9 → 10).

### 추론과 정확도 (3.6.2)
```python
def get_data():
    (x_train, t_train), (x_test, t_test) = load_mnist(normalize=True, flatten=True, one_hot_label=False)
    return x_test, t_test        # 실력 확인은 시험 데이터로

def init_network():
    with open('sample_weight.pkl', 'rb') as f:   # 같은 폴더라 이름만, rb = 바이너리 읽기
        network = pickle.load(f)
    return network
```
- `sys.path`는 `import`용 목록이다. 파일을 열 때는 `open('경로')`.
- `normalize=True`: 픽셀 0~255 → 0.0~1.0 (**정규화**, 전처리).
- `predict()`는 숫자 하나가 아니라 **확률 10개**를 돌려준다. **인덱스 = 숫자**. `np.argmax(y)`로 0~9 중 하나를 고른다.
- 결과: **Accuracy 0.9352**

### 배치 처리 (3.6.3)
```
X(100,784) · W1(784,50) · W2(50,100) · W3(100,10) → Y(100,10)
```
- 은닉층 뉴런 수(50, 100)는 **설계자가 정한 값**이라 계산으로는 알 수 없다 (책에 적혀 있음 / `.shape`로 확인).
- 양 끝은 고정: W1 앞 = 784(이미지 크기), W3 뒤 = 10(출력 개수). `W의 shape = (앞 층 뉴런 수, 뒤 층 뉴런 수)`.

```python
for i in range(0, len(x), batch_size):
    x_batch = x[i:i+batch_size]
    y_batch = predict(network, x_batch)
    p = np.argmax(y_batch, axis=1)
    accuracy_cnt += np.sum(p == t[i:i+batch_size])
```
| 코드 | 결과 |
|:-|:-|
| `np.argmax(y)` | 표 **전체**에서 하나 |
| `np.argmax(y, axis=1)` | **행마다** (가로로 비교) → 이미지마다의 답 ✅ |
| `np.argmax(y, axis=0)` | **열마다** (세로로 비교) |
